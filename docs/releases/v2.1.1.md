## Solid Signal backgrounds

The notch, Daily Shelf and other Signal surfaces use solid backgrounds by default so the content remains readable over open windows. Enable **Translucent background** in **Settings → Appearance** to use your saved tint and blur. macOS Reduce Transparency takes precedence.
