## What's new

- **App opener:** launch apps and Zera's quick actions with **⌥Space**, fuzzy search and keyboard shortcuts.
- **Clipboard history:** revisit text, links, code, images and files with **⇧⌘V**. Pin useful copies, search history and choose how long to keep it. Enable it in Settings; private copies and excluded apps are skipped.
- Quick commands to find running processes and free TCP ports.

## Fixes

- Safari, Finder and apps in deeper or additional locations now appear in the opener.
- Browse every matching result with the arrow keys; **⌘1–⌘6** opens a tile on the current page.
- Process search includes Zera and full executable paths. Process and port lists show every discovered entry; **⌘R** refreshes them.
- Empty command lists handle arrow keys safely, and reopening the opener restores its search field correctly.
- Clipboard returns to **All** with a cleared search when reopened.
- Reminders return to **Today / All sources**, while unfinished forms remain available.

## Performance and cleanup

- Faster app ranking with fewer repeated settings reads and file-system checks.
- Clipboard stops rebuilding while hidden; image previews no longer retain discarded tiles.
- Bounded image caches, shared thumbnail requests and ordered clipboard-history saves.
- Removed obsolete shelf and buddy implementations plus unused UI code, while keeping the current design and workflows.

Validated with **105 passing tests** and a universal macOS build.
