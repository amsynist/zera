- The Android companion is now **Zera X**. Existing Androp installs can update in place with the same signing key.
- Send live Claude Code permission requests to a paired Android phone using a separate encrypted connection.
- The Zera X Wear OS companion can review supported requests on an unlocked watch with a screen lock. Requests needing more context open on the phone.
- The phone and watch share Zera's Signal typography, colors and controls across approvals, pairing and file sharing.
- Zera X pairing survives app updates, reboots and Mac restarts. Turning approvals off on the Mac revokes the key.
- The watch approval screen is a minimal round Signal face that opens by itself: drag the request right to approve or left to deny. Every Claude request can be decided there. Long actions wrap, and anything over 72 characters is shortened.
- Battery: Zera X checks in with the Mac every 60 seconds, backs off to five minutes while the Mac is unreachable and reconnects when the phone joins a network. Androp file-sharing discovery and its Wi-Fi multicast lock run only while a visible screen or the edge overlay needs them.
