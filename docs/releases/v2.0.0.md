# Zera v2.0.0

## Android originals, straight to your Mac

Androp is now Zera’s Android companion. Send an original photo, video, document or text over your local Wi-Fi or a phone hotspot; no internet connection or cloud relay is required. The Mac receiver runs inside Zera. Photos and videos arrive as their own picture and open after verification; ordinary files are caught by Zera’s notch, with themed progress and a verified save on Shelf. Download Androp.apk from the repository root.

Androp now opens on a photo/video grid, supports lifting and gliding a tile, and includes a Files tab. The optional four-edge background overlay supports source-exported global drags; a caught image can be pushed across or retracted. Share → Androp remains available. Source-app/OEM support varies. Traffic is paired but unencrypted; trusted LANs only.

## One native redesign

A continuous Obsidian notch, the living companion, consistent navigation and controls, Claude/Codex activity together, new Home, Clipboard, Tasks/Focus, PRs, Alerts, Reminders, Teleprompter and optional app shortcuts. Murmur offers on-device Whisper dictation after a model download. Managed agent sessions and observed desktop activity retain distinct capabilities.

## Fresh presentation

A new sharing-first film shows actual Android and Mac UI with restrained device depth. A complete native walkthrough and refreshed screenshots replace the old presentation in README and site/. The Android source and receiver package are included for reproducible builds.

See README.md, docs/ANDROID_SHARING.md, docs/ANDROID_PROTOCOL.md and docs/MEDIA.md for setup, boundaries and recording evidence. Versioned validation is recorded in docs/releases/v2.0.0-verification.md.

The standalone sharing film has kinetic captions, Android-left/MacBook-right labels, a flowing hex backdrop and a continuous native animated wallpaper. Download the clean 5K wallpaper from the site. The separate 80-second full walkthrough now adds 27 kinetic caption chapters, smooth focus moves and a verified native window-layout demonstration. README/site include fresh native screenshots; the old window-manager chapter is historical.

## Post-release hardening — review branch

Direct Settings access in every hover style; remembered notch destinations and view context; Timesheet export inside the island with Yesterday and Back to Tasks; centralized optional permission/speech setup and repair. Running-app activation respects native Spaces policy without applying a launch-time Zera group. Dictation binds to the original editable field, rejects secure input, preserves the clipboard during paste and prevents cancelled model jobs from publishing stale results.

Also fixes an AppKit crash during rapid Clipboard grid/list switches, compact Settings clipping, automatic loss of older completed tasks and pending teleprompter edits on shutdown. Branding and numeric version remain Zera v2 / 2.0.0. These changes are prepared for review; physical multi-monitor/native Spaces acceptance, live microphone testing and macOS-version coverage remain separate from automated fixture results.

The selected notch border/glow style now applies to the live island as well as its preview, with motion paused when closed and Reduce Motion preserved.

## Optional Extras and speech insertion follow-up

Settings → Extras groups App Shortcuts and Android sharing. Fresh installs start with both off. A disabled receiver owns no listener or Bonjour advertisement; disabling disconnects peers, cancels timeouts, drains partial cleanup and rejects stale UI callbacks. Disabled App Shortcuts unregisters its hotkeys. Existing explicit enable choices, pairing and previously saved files are preserved.

External speech insertion now uses one checked native paste after release, preserving the clipboard. Some custom editors acknowledge AX text setters without updating their document; that response no longer causes Zera to skip insertion. Secure-field, original-app, field and cursor checks remain in force.

Teams speech follow-up: prepare Chromium/Electron accessibility when the foreground app changes, including embedded webview helpers owned by that app. This makes focused editable controls available before hold-to-speak in lazy web hosts such as Teams. Preparation stays off the main thread, is bounded and cancelled on replacement/disable; native apps and unrelated helper processes are excluded. No VoiceOver, global privacy or app-launch settings are changed.

### Standalone App Shortcuts

Removed the window manager, legacy arranger, Rift bundle/build requirement, scrolling workspaces, dock/filmstrip, window previews, gesture controls and window-management shortcuts. Settings → Extras now contains App Shortcuts for opening or activating chosen apps. Existing app bindings migrate without carrying workspace assignments. Original preference records remain intact; no app data is deleted.

Zera no longer requests Screen Recording. Accessibility remains available for dictation insertion. Native window management is left to a separately installed manager such as OmniWM. Existing walkthrough footage includes a historical arrangement chapter; it no longer describes a shipped feature.

### App shortcut reliability

Fixed a reproduced teardown bug that left all app shortcuts paused when the recording screen was discarded. Recorder destruction now balances its recording callback, independently of the screen lifetime. Global hotkeys use exclusive registration and dispatch in the input-event turn; an unavailable app binding no longer disables unrelated bindings. Native open/reopen requests replace process-only activation, with fresh bundle-ID lookup first and no per-app symlink scan on the running-app path. Diagnostics record request completion timing without capturing typed text.
