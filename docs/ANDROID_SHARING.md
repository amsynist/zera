# Android sharing inside Zera

Zera owns the native Androp v3 receiver in its process; the separate Androp Mac app is unnecessary. Keep the Android app installed. Use Zera menu → Android sharing to enable receiving, copy the six-digit pairing code, preview arrival, or open the inbox. When possible, the old Androp Mac pairing code is retained. Quit standalone Androp before enabling Zera's receiver: only one app can own port 8989.

The phone and Mac need a shared local Wi-Fi or phone-hotspot connection. There is no internet relay and no Bluetooth transport. Traffic uses paired but unencrypted local WebSockets; trusted LAN only.

A ripple still spans the desktop from the phone's exit direction. **Zera’s existing notch island itself opens** into the receipt; there is no separate status panel. The file card follows the swipe in from that edge; on release it is pulled into the notch and vanishes, and the island's stream starts pouring. The island opens as the swipe begins; its own edge (sides and bottom, fading toward the notch) glows in the theme accent, breathing during the swipe and beating with the tide while bytes arrive. Phone transfers send no light outside the island. Zera leaps to catch the card on release. Photos and videos travel as their own picture (the phone's preview), on the card and in the receipt. The same island shape, rim, palette, typography and companion are reused. Its entire interior fills with liquid according to received bytes, using tonal depth from the selected theme’s accent alone, with a soft pearl edge. Broad surface waves move with Core Animation transforms; switching themes recolors it immediately. Unknown sizes use an indeterminate pool with bytes received, and Reduce Motion stops the wave loops. No audio is recorded or simulated as a measurement. Zera descends from the notch, receives the original with her hands, stays focused while receiving, and celebrates a verified save. File details are fully below the hardware cutout: filename, declared size (or bytes received when length is unknown), transfer percentage, verification and final save/error. On a notchless screen the same surface attaches below the menu bar. Reduce Motion disables spatial motion. A final verified save adds a reference to Zera's Shelf; it never analyses incoming files. Photos, videos and plain text fall onto the screen and open after the verified save; other files drop into the notch. Click the saved receipt to reveal it in Finder. Errors stay visible longer. Cancellation and disabled receiving remove transient UI.

Originals save in Downloads/Androp with safe collision-free names, incremental SHA-256 and final size verification. Streaming remains bounded with eight 256 KiB chunks in flight. No native file cap. Only verified persisted originals reach the Shelf.

AndropKit is a self-contained source snapshot in Packages/AndropKit, exported from the adjacent Androp project with tools/integrate_zera.py; Zera builds without that checkout. Update the snapshot when changing the protocol/core; do not maintain divergent copies. Existing standalone Androp remains available for users without Zera.

Validation: `swift test --package-path Packages/AndropKit` and `swift test --filter AndroidTransferTests`. `ZERA_ANDROP_PORT=18989` plus `ANDROP_INBOX=/private/tmp/test-inbox` isolates a real receiver. `ZERA_ANDROP_PREVIEW=1` holds a UI-only preview for review; it never writes or claims a saved file. The opt-in `ZERA_TEST_ANDROID_INBOX=/private/tmp/zera-native-host-smoke swift test --filter AndroidTransferTests` exercises a real 100 MiB stream through the host and Shelf. Add `ZERA_TEST_ANDROID_RENDER=/absolute/receipt.png` to render the actual island during the transfer.
